# moNa2 — GT1 / GT2 / GT3 / ST

roBaish / moNa2（Seeed XIAO nRF52840構成）向けの非公式RMKファームウェアです。
Vial / Pipetteで、4方向ジェスチャ3組と縦スクロールトリガーを設定できます。

## 1. 使用するファイルを選ぶ

| トラックボール | 配布ZIP | 右 / Central | 左 / Peripheral |
| --- | --- | --- | --- |
| 純正 | moNa2-stock-bundle.zip | moNa2-central.uf2 | moNa2-peripheral.uf2 |
| コロピ換装 | moNa2-coropit-bundle.zip | moNa2-coropit-central.uf2 | moNa2-coropit-peripheral.uf2 |

配布ZIPを展開してください。GitHubから取得する場合は、成功したActionsの **Artifacts** から選びます。
ZIPには左右のUF2、説明、変更内容、著作権・ライセンス表示、SHA256SUMSが入っています。

## 2. 書き込む

1. 現在の設定を残す場合は、Vialで `.vil` ファイルを保存します。
2. 片側ずつUSB接続し、リセットを素早く2回押してブートローダードライブを表示します。
3. 右にはCentral、左にはPeripheralのUF2をコピーします。
4. 再起動後、右をUSB接続し、Vial / Pipetteを再接続して新しい定義を読み込みます。

コピーエラーが出た場合、完了したと判断せず再接続と動作を確認してください。
ファームウェアは保存済み設定やBluetoothペアリングを自動消去しません。
保存済みVial設定がある機器では、下記の初期値より保存済み設定が優先されます。

## 3. Vial / PipetteでGT・STを設定する

好きなレイヤーの物理キーを選び、カスタムキーコードを割り当てます。

| 表記 | 押している間の動作 |
| --- | --- |
| GT1 | トラックボールの4方向を左の仮想十字へ出力 |
| GT2 | トラックボールの4方向を中央の仮想十字へ出力 |
| GT3 | トラックボールの4方向を右の仮想十字へ出力 |
| ST | トラックボールの縦移動をスクロールに変換 |

GTを配置したレイヤーで、対応する仮想十字の上下左右にキーやマクロを設定してください。
出力は現在の有効レイヤーと透過設定に従います。トリガー自体のレイヤー固定はありません。
編集後は自分の `.vil` として保存してください。

アンロックを求められたら、右側の最上段両端（初期配列のY/P位置）を同時に押します。

### ジェスチャ

- 移動量 `abs(X)+abs(Y)>30` で即発火。大きい軸を採用し、同値なら横方向。
- 押したまま150ms以上の間隔で次の動きを検知できます。解放自体では出力しません。
- GTとSTの同時押しはGT優先。
- 異なる番号のGTを複数押した場合は、1種類になるまで出力を止めます。
- 検知中の移動は通常カーソルへ漏れません。

### スクロール

- ST押下中のみ有効。横移動は無視し、解放すると通常カーソルへ戻ります。
- 縦8カウントでホイール1単位。CPI800、方向はRMK既定（invert_y=false）。
- 画面上の方向・移動量はOSやアプリ設定にも依存します。
- 解放・モード切り替え時は移動の端数を破棄します。
- 速度・方向をVialから変更する機能はありません。

## 初期配列・設定

標準配列は8レイヤーです。基本レイヤーはQWERTYで、数字レイヤー・設定レイヤーがあります。
一部キーはタップとホールドで動作が異なるMT/LTです。
配列はVialのキーマップ画面で確認できます。ソースのkeyboard.tomlにも各レイヤーを記載しています。

- TD・マクロ・コンボの設定は空。TD32枠などの編集容量は保持しています。
- GT1 / GT2 / GT3 / STと仮想十字12方向は未割り当てです。
- エンコーダーはPageDown / PageUp。その他レイヤーでは透過です。

## 検証情報・ソースからのビルド

GT/STの処理は実機確認済みの実装です。配布用初期設定については自動検査と左右ビルドを行っています。
配布用初期配列での実機動作は、ビルド結果とは別に確認してください。

Rust 1.96.0と固定した依存バージョンを使用し、`cargo make uf2` でビルドします。
`python3 scripts/package_distribution.py` で同梱物・依存一覧・UF2・ハッシュを検査してZIPを作成します。
依存を変更した場合は、ライセンス一覧の更新が必要です。
