# 共通トラックボール版（試験版）

純正トラックボールとCOROPITを、同じ左右UF2で使用します。
実機確認済みのDD1/DD2純正版 `8febd7295091ead154d117c7d8edd5c4e39a0d55` を基準にしています。
ブランチ：`feat/trackball-unified`。公開リリースとは別の個人用試験版です。

## 書き込みと選択

1. 現在の設定を `.vil` で保存してください。
2. 右側へ `roBa_RMK_GT_UnifiedTest-central.uf2`、左側へ `roBa_RMK_GT_UnifiedTest-peripheral.uf2` を書き込みます。両トラボとも同じファイルです。
3. Vial/Pipetteに接続し直し、最新のキーボード定義を読み込ませます。
4. VialのLayout画面、またはPipetteのレイアウトオプションで **Trackball** を選びます。
   - **Stock**：純正トラックボール（初期値）。
   - **COROPIT**：COROPITへ換装した本体。
5. 選択は次のトラボ入力から反映され、本体の既存設定領域へ保存されます。保存処理を待ってから電源を切ってください。

この選択に再ビルド・再書き込み・再起動は不要です。別レイヤへの切替でもありません。
キーマップと12個の仮想ジェスチャ出力は共通です。トラボ由来のカーソル・GT1〜3・STすべてへ、同じ方向補正を一度だけ適用します。
エンコーダーの回転方向・ホイール対策には変更を加えていません。

## 設定保存

選択値は標準VIA/VialのLayout Optionsに格納し、既存RMKの保存・起動時復元処理を利用します。保存形式を追加しません。
再起動後も同じファームであれば選択を保持します。通常の `.vil` 保存にもLayout Optionsが含まれます。
**古い `.vil` を読み込むと、そのファイルのレイアウトオプション値も読み込まれます。COROPIT使用時は読み込み後にTrackballを確認し、必要なら再選択してください。**
ファーム更新による設定初期化の挙動は既存RMKのままです。導入前の `.vil` 保存は必要です。
機器名を変更する機能は含めていません。

## 実装

- `keyboard.toml`、センサー初期化、SPI配線、CPI、split設定、既存レイヤ・TD・マクロ・Combo・Override初期値を保持。
- センサー出力は従来のStock方向。Layout Optionsのbit 0が1の場合だけ、入力のX/Yを共通ルーターで反転（180度回転）。Z・他デバイスには適用しない。
- 選択変更時にはGTの途中のストローク、STと通常ポインター処理の端数を破棄。モード・ボタン状態・トリガー割当ては保持。
- RMKのLayout Options読み出しを公開し、PointingProcessorに端数だけを消すメソッドを追加。保存処理の変更はテストのみ。
- GT1〜3、ST、DD1+/DD1-、DD2+/DD2-、Override、エンコーダーのホイール対策を保持。
- X/Yの個別反転やXY入替えの任意設定は今回の対象外。

## 検証の区別

自動試験では、実際のVial SET通信→ルーター→マウス/仮想キー出力を通し、両設定のカーソル・縦スクロール・12ジェスチャ、切替時の残留移動破棄を検証します。
フラッシュ試験では、既存の実際の保存タスクを動かし、Stock/COROPITを保存してから記憶領域とKeyMapを再生成し、選択とキーマップの復元を確認します。
既存のDD/Override/エンコーダー回帰試験も実行します。
GUIの画面表示・USB/Bluetooth接続・実センサーの方向は実機確認が必要です。ビルド成功だけを実機確認済みとは扱いません。

実機確認：StockとCOROPITの各本体で選択、カーソル上下左右、GT1〜3の方向、STの上下、再起動後の選択保持、DD/Override/ホイールの従来操作を確認してください。
