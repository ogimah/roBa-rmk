# MB1・MB2の独立ドラッグ保持：COROPIT試験版

対象ブランチ：`feat/drag-lock-mb12-coropit`。GT1〜3・ST・Vial Override・ホイール対策と現行の初期レイアウトを維持しています。公開版は変更しません。

## 書き込みと配置

1. 現在の設定をVialから `.vil` に保存します。
2. 成功したActionsのArtifactsから、右に `roBa_RMK_GT_COROPIT_Drag12Test-central.uf2`、左に `roBa_RMK_GT_COROPIT_Drag12Test-peripheral.uf2` を書き込みます。コピーエラーが出た場合は書き込み完了と判断しないでください。
3. USBとVialを再接続して認識を確認し、必要なら保存した `.vil` を読み戻します。
4. Vialのユーザタブで次の4キーを好きなレイヤー・位置に割り当てます。初期状態では未配置です。

| 表示 | 動作 |
|---|---|
| DD1+ | 左ボタン（MB1）の保持を開始 |
| DD1- | 左ボタンのDD保持だけを解除 |
| DD2+ | 右ボタン（MB2）の保持を開始 |
| DD2- | 右ボタンのDD保持だけを解除 |

開始キーはタップして離しても保持します。繰り返し押しても解除にはなりません。対応するマイナスキーで解除します。レイヤーの固定条件はありません。

以前のDD+／DD-のキーコードは変更していません。保存済みの割り当ては、左用のDD1+／DD1-として継続できます。

左右のDD保持は独立しています。両方を有効にした場合、DD1-を押しても右は保持され、DD2-を押しても左は保持されます。
通常クリックとも別管理し、通常クリックの解放だけではDDを解除しません。物理ボタンを押したまま対応するマイナスキーを押した場合は、DDだけ解除し、物理ボタンは離すまで保持します。

DDの状態は保存しません。実際の出力先変更、出力中のBLEプロファイル変更、切断で左右とも解除し、再接続へ持ち越しません。未接続時の開始キーで保持を予約しません。

## 実機確認

- 左：DD1+をタップ → トラボで移動 → DD1-でドロップ。
- 右：DD2+をタップ → トラボで移動 → DD2-で解放。右ドラッグの用途・結果はアプリに従います。
- 左右の同時保持と片方だけの解除、通常クリックとの共存。
- ST・エンコーダー・GT1〜3・Override・通常入力が従来どおり動く。
- USB／BLE切替・切断・再接続で、どちらの保持も復活しない。

MB1のみの旧試験版は実機で機能したとの報告があります。この左右対応版・COROPIT版の実機確認は別途必要です。

## 実装・ソフトウェア試験

User14／15をDD1+／DD1-として維持し、User16／17をDD2+／DD2-として追加。
BLE・CLR_PEER・GT/ST・Overrideの番号・設定は変更しません。
保持は通常のクリック状態と独立した2ビットとして管理し、接続状態と同じロックで更新します。
すべてのマウス出力へ送信直前に合成し、キュー待機後には再取得します。
既存の7試験に加え、左右の開始・解除順序、両保持中の移動・スクロール・エンコーダー、右クリックとの共存、両保持の接続切替解除を試験します。
Vial通信から4キーを配置し、両保持中のSTとGT3組も確認します。

ソフトウェア試験とビルドの成功は、実機動作の確認とは区別します。
