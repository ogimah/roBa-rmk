# Bluetooth名変更試験版

トラボ共通版 `7ff670706bae33c25a506bfd85293e1307ddd65a` を基準とする個人用試験版です。
ブランチ：`feat/ble-name-vial`。main・公開リリースは変更していません。
Vial/Pipetteの改造・追加アプリ・名前変更ごとの再ビルドは不要です。

## 操作手順

1. 導入前に現在の設定を `.vil` で保存します。
2. 右へ `roBa_RMK_GT_NameTest-central.uf2`、左へ `roBa_RMK_GT_NameTest-peripheral.uf2` を書き込みます。Stock/COROPIT共通です。
3. Vial/Pipetteを接続し直します。必要ならTrackballをStock/COROPITへ設定します。
4. **空いているマクロ枠**を一つ開き、**Text（文字列）の本文**に `BLE_NAME=roBaish` などと入力して保存します。マクロの表示名ではありません。
5. 保存完了から **2秒待ちます**。
6. Userタブの **BN**（内部名BN_APPLY）を任意の物理キーに配置し、そのキーを1回押します。設定用マクロ自体をキーに割り当てて実行する必要はありません。
7. **2秒待って本体を再起動**し、Bluetoothで名前を確認します。USBを抜いても電池から給電されている本体は、電源スイッチで再起動してください。

例：`BLE_NAME=roBaish`、`BLE_NAME=moNa2-COROPIT`。
名前部分は半角英数字・記号・空白で1〜16文字です。日本語・改行・空名・空白だけの名前は受け付けません。`BLE_NAME=`は大文字で記述します。
候補は全32枠の中で一つにしてください。Text以外のTap/Down/Up/Delayを混ぜないでください。
マクロ保存途中や保存直後1秒以内のBN操作も受け付けません。設定用枠を通常マクロとして実行すると文字入力されるため、実行用のキーには割り当てないでください。

## 保存と反映

- BNで検証済みの名前を**マクロとは別の本体保存項目**へ保存します。保存後に設定用マクロを削除・変更しても、名前は残ります。
- 通常のマクロ保存や `.vil` 読込みだけでは名前を変更しません。変更はBNを押したときだけです。
- 新しい名前は**再起動後**のBLE広告名とGATT Device Nameに共通適用します。USB製品名・Vial表示名・UIDは変更しません。
- BN操作にGUIの成功メッセージはありません。エラー通知はファームのログのみで、入力不正・候補重複・保存失敗では新しい名前を採用しません。再起動後の確認が必要です。
- OSが以前の表示名をキャッシュしている場合、広告/GATT名が変わっていても一覧表示がすぐに変わるとは限りません。既存ペアリングを保持した再接続と、新規検索時の表示は別に確認してください。
- アドレス・IRK・ボンド・左右接続アドレスを名前変更処理から書き換えません。
- `.vil`へは標準のマクロとして設定文字列が保存されます。本体初期化や別の本体への移行時は、そのマクロを復元し、BNで再適用してください。独立した保存名を標準.vilの専用項目へ追加する方式ではありません。

## 既存機能と導入時の移行

GT1〜3・ST・DD1+/DD1-・DD2+/DD2-・Override・ホイール対策・Trackball選択・既存キーマップ/TD/マクロ/Comboを保持します。User0〜17の番号も変更しません。
マクロ枠を強制的に予約・上書きしません。512バイトの既存マクロ容量の空きを使います。

従来のRMKはビルド識別値の不一致で全設定を消去します。今回は、同じ個人用0.9系（5×11・8レイヤ・1エンコーダ・マクロ512バイト・既存容量）の保存データを検証できた場合だけ、全消去せず識別値を移行します。
既存440セル・8レイヤのエンコーダ・動作設定・保存済みマクロ/TD/Combo/Override・ボンド/左右接続情報等の型を確認します。名前用の保存キーとデータ型は列挙の末尾へ追加し、既存の符号を変えません。
別形式や破損した保存領域を無条件に引き継ぐ処理ではありません。意図的なclear_storageと元の非互換初期化経路は維持しています。
設定・ペアリング保持は自動試験で確認した範囲です。実機での移行は未確認のため、事前の.vil保存は必要です。

古い `.vil` の `layout_options` が `-1` の場合、Vialが読込み途中でエラーになります。以前の案内どおり `0` へ修正して使用し、COROPITの本体では読込み後にTrackballを選択し直してください。
